GitHub key for the reading board

The board is saved in the project's GitHub repository, so the daily picks can skip papers you've saved. To let this site save it, give it a GitHub key once on each device. The key stays in this browser and is sent only to GitHub.

Checking…

  1. Create a fine-grained key on GitHub.
  2. Under Repository access, choose Only select repositories and pick {{ repo.split("/")[1] }}.
  3. Under Permissions → Repository permissions, set Contents to Read and write. Nothing else is needed.
  4. Press Generate token, copy it, and paste it here.
