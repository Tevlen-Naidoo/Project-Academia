GitHub key for the reading board

The board is saved in the project's GitHub repository, so the daily picks can skip papers you've saved. To let this site save it, give it a GitHub key once on each device. The key stays in this browser and is sent only to GitHub.

Checking…

  1. Create a fine-grained key on GitHub.
  2. Under Repository access, choose Only select repositories and pick {{ repo.split("/")[1] }}.
  3. Under Permissions → Repository permissions, set Contents to Read and write. Nothing else is needed.
  4. Press Generate token, copy it, and paste it here.

Notifications

Get a notification on this device when the day's papers are up, usually before 7am SAST. Tapping it opens Today. Turn it on once on each device.

On iPhone and iPad (iOS 16.4 or later):

  1. In Safari, tap the Share button, then Add to Home Screen.
  2. Open Academia from your Home Screen and go to Settings.
  3. Tap Turn on notifications and allow them.
  4. Copy the sign-up code it shows into the Add notification device workflow on GitHub.

Checking…

Sign-up code for this device

To finish, copy this code, open Add notification device on GitHub (the GitHub app works), tap Run workflow, paste the code and run it. A test notification arrives within a minute or two. You only do this once per device.
